## Data Types
Data Types define what kind of value a variable stores.JavaScript provides different types to handle text,numbers,true/false values and collection of data.
## String
Stores text values like names,titles and input data.
## Variables
Variables are used to store values so they can be reused throughout the program.
They help make the code dynamic instead of hardcoding the data.
## Arrays
Stores multiple values in a list format. Useful when working with multiple data like users,products, or links.
## Objects
Stores related data together using key-value pairs.Commonly used for grouping test data such as login details or configurations.
## Functions
Functions group multiple steps together into a reusable block.They help avoid repeating the same code and make programs cleaner and easier to maintain.
## Arrow Functions
Arrow functions are a shooter and modern way of writing functions.They are widely used in modern javaScript and automation projects.
## Parameters
Parameters allow functions to accept inputs,making them flexible and reusable.
## Return Values
Return values allow functions to send results back after execution.

## CONDITIONS(if / else)
Conditions allow the program to make decisions. They execute different actions depending on whether the condition is true or false.Used frequently for validations and test result checks.
## Async & Await
Some operations take time to complete such as loading data or performing external tasks.
JavaScript handles these using asynchronous behaviour.
## Async 
Marks a function as asynchronous, meaning it may take time to complete.
## Await
Pauses execution untill the task finishes before moving to the next step.
## Importance of Async/Await
Ensures steps execute in the correct order and prevents unstable pr unpredictable behaviour.
This concept is critical for reliable automation scripts.
## Classes
Classes are used to group related actions together in one place.They help organize code and improve structure and readability.In automation,classes are commomly used to represent pages or modules.
## Methods
Methods are functions defined inside a class.They perform specific actions related to that class.
## Objects & Method Calling
Objects are instances created from classes.They allow access to the class methods.Methods are called using the dot operator.
## Constructor 
The constructor runs automatically when an object is created.It is used to initialize or set up initail values.

## TypeScript For Automation Testers
## 1. What is TypeScript
TypeScript is JavaScript with the types.It adds safety by catching errors during development instead of runtime.
## 2. Why TypeScript for Automation
TypeScript provides better auto-complete,fewer bugs, and clearer code.This makes automation frameworks easier to build,read and maintain.
## 3. Types (Core Idea)
Types define what kind of value a variable can store.This prevents invalid data and reduces mistakes.
